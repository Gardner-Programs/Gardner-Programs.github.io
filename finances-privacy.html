Finances — Privacy Policy

Last updated: November 20, 2026

Finances is a private, personal-use tool. It is not offered to the public: it runs on its owner's own computer and is used only with the owner's own Google accounts. This policy explains what it accesses and how that data is handled.

Data We Access

Through Google OAuth2, Finances reads the owner's Gmail messages (to record bank alerts and order receipts and to summarize what needs attention), manages Gmail settings such as filters, and adds or removes labels on messages to organize the inbox.

Google OAuth Scopes

  • gmail.readonly and gmail.modify — read messages and organize them with labels. Finances never permanently deletes email.
  • gmail.settings.basic — create and manage inbox filters.

Where Data Is Stored

Anything Finances keeps (for example transaction records and processing notes) is stored only on the owner's computer. OAuth tokens are stored in a local file readable only by the owner's user account. Nothing is stored on any server operated by Gardner Programs, and no data is sold or shared.

Third-Party Services

  • Google Gmail API — to read and organize the owner's email.
  • Anthropic (Claude) — receives sender, subject and short previews of recent emails to produce a private daily summary for the owner.
  • ntfy — delivers short notifications to the owner's own phone.

Use of Google User Data

Finances' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used only to provide features to the owner and is never used for advertising.

Revoking Access

Access can be removed at any time at Google Account Permissions by removing "Finances" from the list of connected apps.

Contact

Questions can be sent through Gardner Programs on GitHub.
